# 關於繁體字的 Native Check
剛好工作上遇到需要處理繁體字的 Native Check，順便記錄一下檢查時的想法。

- 紀錄 or 記錄 
  - 「紀錄」是名詞，指的是「記錄的內容」。例如：使用紀錄。
  - 「記錄」是動詞，指的是「把事情記下來」。例如：我要記錄這件事。

- Toll Roads
  - 台灣收費道路幾乎都是高速公路，所以會想用「高速公路」來翻譯 Toll Roads。但日本或韓國的收費道路並不全是高速公路，有些是一般道路。因此，直接翻譯成「收費道路」會比較合適。

- 付款 or 支付
  - 「付款」通常指的是支付現金或刷卡等實際的金錢交易行為。
  - 「支付」則是比較廣義的詞彙，可以涵蓋各種支付方式，包括電子支付、轉帳等。但有種支語的感覺，很想避免使用。

- 標點符號
  - 根據中華民國教育部所頒布的[《重訂標點符號手冊》修訂版](https://language.moe.gov.tw/001/upload/files/site_content/m0001/hau/Revised_Handbook_of_Punctuation.pdf)，不論直式或橫式書寫，中文標點符號皆應使用全形標點符號並且「居中」。
  - 在日文或是簡體中文裡，橫式會靠在左下角，直式會靠在右上角。
  - Unicode 中雖說全行的標點符號編碼相同，但實際上根據不同語言設定，會有不同的顯示方式。因此在處理多語系時，建議使用對應語言的標點符號。
