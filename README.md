# lavaday1225

Personal website of Jerry （ジェリー） — a Golang backend developer from Taiwan, based in Tokyo.

🌐 **Live site:** https://lavaday1225.github.io/lavaday1225/

## What's inside

- **Tech Blogs** — backend engineering write-ups: Go, databases (MySQL index internals, R-tree), RFC notes
- **Notes** — shorter study notes and checklists
- **Lifes** — life in Tokyo: volleyball, cooking, and everyday notes
- **About** — profile and social links

## Built with

- [VitePress](https://vitepress.dev/) 1.6 + vitepress-sidebar
- Deployed to GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`)

## Local development

```bash
npm install
npm run docs:dev     # start the dev server (or: make local)
npm run docs:build   # build the site
npm run docs:preview # preview the production build
```
